# 1. SpiderFoot — запуск скана из Raven (раздел 11)

Сделано: манифест интеграции, чтение результатов через http-исполнитель рантайма (эндпоинт /scaneventresults своего инстанса), парсер событий, таблица маппинга типов событий в сущности (domain, url, email, username, ip, repo, наблюдение), маппинг в узлы и связи с указанием модуля, типа события, источника, времени, confidence и сырой записи, действие «Открыть в SpiderFoot», регистрация одной строкой в BUILTIN_SOURCES.

Не сделано: Raven пока не запускает скан сам — аналитик запускает его в своём SpiderFoot и вводит id скана. Нужно: POST на создание скана, опрос статуса с бэкоффом, отмена, частичные результаты, проба возможностей инстанса (§4.2 спеки).

# 2. Sherlock — проба возможностей инстанса и вотчлист (раздел 12)

Сделано: манифест (контейнер в песочнице рантайма, образ по digest, read-only, gVisor, приватные диапазоны запрещены), вход username из выделенного узла, запуск из карточки узла и из палитры («Run integration…»), защитный парсер трёх форм JSON с правилом «непонятный ответ — не попадание», проверка ссылок профилей на SSRF, маппинг найденных профилей в узлы и связи username -> profile, обработка отмены и частичного результата, регистрация одной строкой (без digest интеграция просто не появляется).

Не сделано: проба версии и флагов образа (§3.6 спеки), диф повторного запуска и вотчлист (§6.5, §6.6).

# 3. Автоматическое исследование GitHub-репозиториев (разделы 14, 37)

Сделано: интеграция github в реестре, парсер репозитория/владельца/домашней страницы/контрибьюторов, анализ репозитория в packages/domain.

Не сделано:
- структурированный Repository Analysis в интерфейсе (язык, архитектура, entry point, интерфейсы, сложность интеграции, зависимости, возможный адаптер, возможные типы узлов);
- Integration Proposal как результат анализа;
- разбор ошибок анализа с действиями Retry / Open Repository / Analyze Manually вместо общего сообщения об ошибке;
- действия на самом узле репозитория.

# 4. Глобальный поиск и палитра команд (раздел 17)

Проверено в приложении 2026-08-22: Ctrl+K открывается, но при вводе запроса показывает «No commands yet», хотя на доске есть узлы.

Нужно:
- поиск по узлам, связям, тегам, заметкам, файлам, проектам, именам пользователей, репозиториям и результатам инструментов;
- команды в палитре: создать узел, открыть проект, запустить интеграцию, сменить режим холста, выполнить действие;
- переход к найденному узлу с центрированием камеры.
